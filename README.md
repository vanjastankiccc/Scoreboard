A simple interactive scoreboard that allows tracking points for two teams: Home and Away.

📌 Features

- Add points for **Home** and **Away** teams
- Supports +1, +2, and +3 scoring options
- Real-time score updates
- Easy reset functionality
- Clean and minimal user interface

🏀 Possible Use Cases

While inspired by basketball scoring, this scoreboard can also be used for:
- Basketball games
- Classroom competitions
- Friendly matches or tournaments
- Any custom point-based game

🛠️ Built With

- HTML
- CSS
- JavaScript
